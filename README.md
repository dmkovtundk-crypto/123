# FlexGlobalLogistics — демо-страница корпоративного портала

В репозитории добавлена стартовая HTML-страница `index.html`, которую можно открыть локально.

## Как посмотреть страницу

1. Откройте терминал в папке проекта:
   ```bash
   cd /workspace/123
   ```
2. Запустите локальный web-сервер:
   ```bash
   python3 -m http.server 4173
   ```
3. Откройте в браузере:
   ```
   http://localhost:4173
   ```

## Что сейчас есть
- Визуальный черновик главной страницы корпоративного портала.
- Блоки: роли сотрудников, общие ресурсы, объявления, журнал входов.
- Секция с быстрыми переходами на внешние сервисы компании.
